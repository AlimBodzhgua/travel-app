# Travel App

A web application for organizing trips both independently and with other users with the integration of mapping services for route planning.

# Technology stack
- [React](https://react.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [ReduxToolkit](https://redux-toolkit.js.org/)
- [StoryBook](https://storybook.js.org/)
- [i18n](https://www.i18next.com/)
